What it does, in one keystroke

High-fidelity Markdown

Defuddle-extracted body, Turndown + GFM tables, code-fence preservation, math (LaTeX from MathML), footnotes, frontmatter — the things every other clipper breaks.

Save where you keep notes

Pick your Obsidian vault folder once. Files land there directly via the File System Access API — no sync server, no cloud round-trip, no copy-paste. Obsidian URI handoff opens the file immediately if you want it.

Local-first, privacy-respecting

No analytics, no telemetry. Activated only when you click the toolbar button or press the keyboard shortcut — never on a tab you didn't ask for. Open source clipping engine.

Built-in site rules

Reddit, Hacker News, Stack Overflow, GitHub README, ChatGPT/Claude/Gemini conversations, news sites — all pre-tuned. Add your own rules in seconds (Pro).

Image control, your way

Inline as base64 (free), reference the original URL (free), or co-locate binary image files alongside the .md file (Pro). Whatever your vault structure expects.

Multi-tab batch (Pro)

Open 30 research tabs, clip them all into your vault with one shortcut. The free tier supports up to 3 tabs at a time; Pro removes the cap.
